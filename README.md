# Portfolio - Armando Gómez

Sitio web personal desarrollado para mostrar mis proyectos, experiencia y habilidades como desarrollador Fullstack y diseñador UI/UX.

---

## 🚀 Tecnologías utilizadas

- ⚡ Astro
- 🎨 Tailwind CSS
- 🧠 JavaScript
- 🧩 Diseño UI/UX en Figma

---

## ✨ Características

- 🎯 Diseño moderno y centrado en el usuario
- 📱 Responsive (mobile-first)
- ⚡ Animaciones suaves y microinteracciones
- 🧊 Navbar con efecto glassmorphism al hacer scroll
- 🎨 Sección de proyectos interactiva con hover effects
- 🧩 Componentización reutilizable en Astro

---

## 📂 Estructura del proyecto

```bash
src/
 ├── assets/        # Imágenes e íconos
 ├── components/    # Componentes reutilizables
 ├── layouts/       # Layout principal
 ├── pages/         # Páginas del sitio
 └── styles/        # Estilos globales
```
